# 配方清单（含风险分级）

> 风险提示贴在**每个配方旁边**，不写在文末——提示出现在决策点才叫提示。

## 判定标准

四个问题，任一为"是"就往上抬一档：

1. 有没有拿走别人的东西（内容、数据、钱）？
2. 有没有绕过付费、授权、实名这类门槛？
3. 会不会伤到你自己（账号、隐私、资金）？
4. 自己用，还是要传播/商用？

**档位不只看脚本，更看用途。** 同一个"解除复制限制"脚本：自己复制一篇新闻存档 = 🟢；批量爬整站建成自己的网站 = 🔴。

## 🟢 绿色 — 只改你屏幕上看到的东西

直接装，零废话。

| 配方 | 干什么 | 脚本/来源 |
|---|---|---|
| GitHub 界面中文化 | 菜单、按钮、设置项全变中文 | maboloshi/github-chinese（29k★） |
| 购物历史价格曲线 | 京东/淘宝页面直接显示价格走势 | 慢慢买等（公开数据） |
| 网页视频倍速/截图/画中画 | 任意页面视频 0.5~4 倍速 | Video Speed Controller 等 |
| 去登录弹窗 / 展开全文 | 知乎、微博、小红书等 | 各站点增强脚本 |
| 网页深色模式 / 护眼配色 | 强制给任意网站套深色主题 | Dark Reader 类 |
| 阅读模式（正文净化） | 去掉侧边栏和广告位，只留正文 | 只看，不拿 |
| B站自定义皮肤 / 界面清爽化 | 不改下载、不动广告 | Bilibili 美化类 |
| 自动填写自己的地址 / 邮箱 | 填的是你自己的信息 | 各类表单助手 |

## 🟡 黄色 — 违反平台协议，个人用几乎没人管，但别扩散

**处理：一句话告知风险，等用户确认。**

| 配方 | 风险说明 |
|---|---|
| 跳过视频网站贴片广告 | 国内多个判例认定广告拦截构成**不正当竞争**（优酷、芒果TV 胜诉）。但被追责的**全是开发者/分发者**，没有普通用户因自装插件被起诉的先例。个人自用风险低，违反平台协议。 |
| 下载B站/视频站视频离线看 | 违反平台协议。个人自看实践中无人管；**一旦传播立刻变红**。 |
| 音乐缓存解密（网易云/QQ音乐） | 自己听是灰色；传出去立刻变红。 |
| 自动签到 / 自动做任务 | 违反协议，账号有封禁风险。 |
| 导出自己账号的数据 | 违约但不算侵权（知乎收藏、微博内容等）。 |
| 强制登录墙后取公开内容 | 灰色，视站点条款而定。 |
| 批量取消关注 / 批量清理 | 容易触发风控封号。 |
| Bilibili Evolved | 功能全（含下载、去广告）。个人自用风险低，含黄色功能需告知。 |

## 🔴 红色 — 直接违法，或者害你自己

**处理：拒装 + 简短说明理由。不做例外。**

| 配方 | 为什么 |
|---|---|
| 把下载的影视剧/付费课程传到网盘分享 | 侵犯著作权，量大可入刑 |
| 绕过付费墙（付费文章、会员视频、付费课程） | 侵犯著作权 + 不正当竞争 |
| 脚本偷 Cookie / 账号密码 / 钱包私钥 | 恶意脚本 = 黑客工具 |
| 剪贴板劫持（复制收款地址被替换） | 直接造成资金损失 |
| 爬取平台数据倒卖 | 侵犯公民个人信息 / 不正当竞争 |
| 刷单、薅羊毛、抢购机器人 | 可能构成破坏计算机信息系统罪 |
| 去水印后商用 | 侵犯著作权 |
| 绕过实名认证 / 年龄限制 | 违法 |
| 会员视频"免费看"类脚本 | 要么侵权，要么本身就是钓鱼 |

## 来源可信度（第二维度）

**功能再绿，来源危险也不装。**

| 来源特征 | 处理 |
|---|---|
| 万级 star、开源可读、近期有更新 | 放心装 |
| 数千 star、评论区正常 | 正常装 |
| 匿名上传、代码混淆、上架几周 | ⚠️ 先审源码再决定 |
| 源码含 `eval(atob(...))`、往陌生域名发数据 | 🔴 直接拒 |
| 名字承诺"破解""免费看会员""无限刷" | 🔴 直接拒 |

**体检命令**（安装前跑一次，扫危险模式）：

```bash
curl -sL "<脚本.user.js 地址>" -o /tmp/s.user.js
grep -nE "eval\(atob|eval\(unescape|document\.cookie|localStorage\.getItem\('token|fetch\('https?://[^g]" /tmp/s.user.js
wc -l /tmp/s.user.js && head -40 /tmp/s.user.js
```

人工看一眼头部注释（@match 范围、@grant 声明）——一个"知乎增强"却声明 `@match *://*/*` 就是可疑信号。
