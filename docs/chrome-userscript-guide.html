一页搞定：让 Chrome 用上用户脚本

以「GitHub 界面中文化」为例 · macOS / Windows 通用 · 全程约 3 分钟

先搞清楚这是怎么回事

你要装的是两样东西：一个叫 篡改猴（Tampermonkey） 的扩展，加上一个具体功能的 用户脚本。篡改猴本身不翻译任何东西——它是个「网页改装平台」，装上脚本之后才会起作用。

有三步必须你亲手点，这不是偷懒，是浏览器的安全设计。用户脚本能以你的身份读写所有网页， 所以厂商刻意把授权设计成「必须本人点头」，任何程序都绕不过去。

操作步骤

装篡改猴

Chrome 应用商店搜索「篡改猴」或「Tampermonkey」，点「添加至 Chrome」。

如果弹出「要添加…扩展程序吗？」的确认框，点「添加扩展程序」。

打开「允许用户脚本」开关 新版 Chrome 必须做

地址栏输入 chrome://extensions 回车，找到「篡改猴」卡片：

  • 卡片上的开关如果是灰的 → 先打开它（若弹出「启用扩展程序」就点它）
  • 点卡片上的「详情」 → 往下滚 → 打开「允许用户脚本」
这一步最容易漏。Chrome 138 版之后新增了这道开关，光启用扩展是不够的—— 开关不开，脚本装了也不会跑，页面看起来「什么都没发生」。

安装脚本

打开脚本页面，点绿色的「安装此脚本」，会跳到一个篡改猴的确认页， 再点上面的「安装」。

GitHub 中文化脚本直装链接：
update.greasyfork.org/scripts/435208

装完回到目标网页，按 Cmd+R（Windows：Ctrl+R）刷新。

怎么确认真的成了

三个问题逐条问自己，全「是」才算完成：

自查怎么看
扩展启用了吗 chrome://extensions 里篡改猴的开关是蓝色的
开关开了吗 详情页里「允许用户脚本」是打开的
页面变了吗 刷新后亲眼看——GitHub 顶部菜单变成「平台 / 解决方案 / 开源」就是成了
只看设置对不对是不够的。曾经出现过「所有开关都正常，但脚本在扩展被重置时丢了」的情况—— 所以最后一定用眼睛确认页面。

出问题怎么办

点击「安装此脚本」后没反应 / 弹出的是乱码代码页

说明篡改猴没启用，或「允许用户脚本」没打开。回到步骤 2 检查这两处，然后重试。

全部设置都对，刷新了还是英文

大概率是脚本没真正装进去。去篡改猴的控制台看「已安装脚本」列表里有没有它； 没有就重装一次脚本。重装前记得先确认上面两个开关是开的。

装了汉化，但页面还是有一堆英文

汉化脚本只覆盖界面文字（菜单、按钮、设置项）。README 正文、 讨论区留言这类大段内容不在范围内——那需要用翻译类扩展单独处理。

Chrome 自带的「翻译成中文」弹窗要不要点

可以关掉。它把你的页面内容发给翻译服务器，和本地汉化脚本是两回事； 万一哪天它和汉化脚本同时生效，反而会互相打架。

工具栏上看不到篡改猴图标

点工具栏右上角的拼图图标，里面能找到；旁边的图钉可以把它固定到工具栏。

以后 GitHub 改版了会不会失效

不会。这类主流脚本会自动更新词库，GitHub 改界面它自己会跟上，不用你管。

装上之后还能干什么

篡改猴是个通用平台，社区里现成的脚本有几万个。下面按风险分三档， 这是装之前应该知道的事——工具本身不违法，看怎么用。

档位典型用途说明
放心用 界面汉化、购物历史价格、视频倍速/截图、去登录弹窗、深色模式、阅读模式 只改你屏幕上看到的东西，不碰别人权益
自己用没事 跳过视频贴片广告、下载视频离线自看、自动签到、导出自己账号数据 违反平台协议，个人自用实践中无人追究； 但别拿去传播或商用，那会直接变成下一档
别碰 把下载的影视/课程传出去分享、绕过付费墙、爬数据倒卖、刷单抢购、去水印后商用 侵犯著作权或构成其他违法，风险全在你自己身上

比「违不违法」更现实的一个风险

脚本市场是开放平台，里面混着恶意脚本——假借「增强」「去广告」之名， 实际偷你的登录凭据、劫持剪贴板（你复制收款地址，它给你换成别人的）、往页面里塞推广。 装之前看一眼：星标多不多、最近有没有更新、源码能不能看懂。 名字里带「破解」「免费看会员」「无限刷」的，一律别装。

装完之后的三条边界（就三句话）

  • 黄色档的用途只在自己的设备上自用，不商用、不分发、不二次开发牟利
  • 不传播下载来的版权内容
  • 发现异常（登录态丢失、剪贴板内容被改、莫名跳转）→ 立刻停用那个脚本
